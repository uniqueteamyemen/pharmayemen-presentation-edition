# PharmaYemen — النسخة المعروضة القابلة للنقل

هذه نسخة كاملة قابلة للتشغيل والتدقيق من منصة **PharmaYemen**، أُعدت للتوثيق والعرض أمام الجهات الرسمية. تحتوي على واجهة المستخدم، تدفق العرض والطلب، المطابقة الاسمية، طبقة الأسماء التجارية، لوحة المؤشرات الإدارية، مخطط MySQL، وترحيلات قاعدة البيانات. لا تتضمن بيانات إنتاج، أسراراً، أو ربطاً بمنصة Manus.

## ما الذي انفصل عن النسخة التشغيلية؟

| المكوّن | النسخة التشغيلية الأصلية | النسخة المعروضة |
|---|---|---|
| تشغيل الخادم | طبقة تشغيل مدارة | Express وVite قياسيان |
| المصادقة | OAuth خاص بالبيئة الأصلية | حسابات محلية مع جلسات JWT وملفات تعريف ارتباط آمنة |
| قاعدة البيانات | متغير بيئة مُدار | `DATABASE_URL` قياسي لـ MySQL |
| البريد | رابط تواصل عام فقط | نفس رابط `mailto:` العام؛ لا يوجد SMTP أو مزود ظاهر |
| التخزين والإشعارات الخاصة | غير مفعّلة ضمن هذا الإصدار | معزولة ولا تمثل متطلباً لتدفقات العرض والطلب والمطابقة |

> النسخة لا تنقل أي سجل من المستخدمين أو العروض أو الطلبات أو بيانات الدخول. تعتمد على مخطط القاعدة والترحيلات فقط.

## التشغيل المحلي

يلزم Node.js 22+ وpnpm 10+ وMySQL 8+. انسخ `.env.example` إلى `.env` وضع كلمة مرور وقيمة JWT عشوائية لا تقل عن 32 حرفاً.

```bash
docker compose up -d mysql
pnpm install
pnpm drizzle-kit migrate
pnpm dev
```

بعد بدء الخادم، افتح `http://localhost:3000`. استخدم شاشة تسجيل الحساب لإنشاء أول حساب. الحساب الذي يطابق بريده `BOOTSTRAP_ADMIN_EMAIL` يحصل على دور المدير تلقائياً.

## البناء والنشر القياسي

```bash
pnpm check
pnpm test
pnpm build
NODE_ENV=production pnpm start
```

تحتاج أي استضافة Node.js قياسية إلى: `DATABASE_URL` آمن، و`JWT_SECRET` قوي، وHTTPS في طبقة النطاق/الوكيل، وقاعدة MySQL بعد تطبيق الترحيلات. لإضافة SSO مؤسسي لاحقاً، يُستبدل فقط موصل الحساب المحلي بمزوّد OIDC مع الحفاظ على جلسة المنصة وطبقة الصلاحيات.

## نطاق العرض الرسمي

المنصة ليست صيدلية أو متجراً إلكترونياً ولا تستقبل مدفوعات. وظيفتها إظهار إشارات العرض والطلب، المساعدة في التعرف على الأدوية، المطابقة الاسمية، والمؤشرات السوقية الخاضعة لصلاحيات الإدارة. لا ينبغي اعتبار أي مثال محلي أو سجل ينشئه المختبر بياناً حقيقياً عن سوق الدواء اليمني.

## الأمن والخصوصية

تُشفّر كلمات المرور محلياً باستخدام `scrypt` مع ملح عشوائي، ولا ترجع واجهة API تجزئة كلمة المرور. تحمل الجلسة JWT موقعة في ملف تعريف ارتباط `httpOnly` و`SameSite=Lax`، ويُفعَّل علم `Secure` عند HTTPS. لا تحفظ تحليلات الفئات العلاجية هوية المستخدم أو نص البحث الحر.

للتفاصيل، راجع أيضاً `PORTABLE_ARCHITECTURE_AR.md` و`PRODUCTION_READINESS_AND_SECURITY_REPORT_AR.md`.
